## Overview

This application uses **ngx-translate** for internationalization, combined with **NgRx** for state management. The system supports:

- ✅ **Multiple languages**: English, French, Arabic (RTL support)
- ✅ **Persistent selection**: User's choice saved in localStorage
- ✅ **Automatic detection**: Browser language detection on first visit
- ✅ **SSR compatible**: Works with Server-Side Rendering
- ✅ **No FOUC**: No Flash of Untranslated Content
- ✅ **API integration**: Automatic language headers in HTTP requests

### Currently Supported Languages

| Language | Code | Direction | Flag |
| -------- | ---- | --------- | ---- |
| English  | `en` | LTR       | 🇬🇧   |
| French   | `fr` | LTR       | 🇫🇷   |
| Arabic   | `ar` | RTL       | 🇹🇳   |

## Architecture

### State Management Flow

```
┌─────────────────────────────────────────────────────────────────┐
│                      i18n ARCHITECTURE                           │
└─────────────────────────────────────────────────────────────────┘

┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│  localStorage│◄────►│ LanguageService│◄────►│ TranslateService│
│  (Persist)   │      │  (Orchestrator)│      │  (Engine)    │
└──────────────┘      └───────┬────────┘      └──────────────┘
                              │
                              │ Dispatches
                              ↓
                      ┌──────────────┐
                      │  NgRx Store  │
                      │  (State)     │
                      └───────┬──────┘
                              │
                              │ Selectors
                              ↓
                      ┌──────────────┐
                      │  Components  │
                      │  & Interceptor│
                      └──────────────┘
```

### Key Components

1. **localStorage**: Persists language across sessions
2. **NgRx Store**: Reactive state management
3. **TranslateService**: Loads and applies translations
4. **LanguageService**: Orchestrates language switching
5. **HTTP Interceptor**: Adds language headers to API requests

## How It Works

### 1. Application Initialization

```
┌─────────────────────────────────────────────────────────────────┐
│ INITIALIZATION SEQUENCE                                          │
└─────────────────────────────────────────────────────────────────┘

1. App Bootstrap
   ↓
2. NgRx Store Initializes
   └─ Initial state: { currentLanguage: 'en' }
   ↓
3. APP_INITIALIZER Runs
   └─ LanguageService.initialize() executes
      ├─ Checks localStorage for saved language
      ├─ Or detects browser language
      ├─ Loads translation file (e.g., fr.json)
      ├─ Applies text direction (LTR/RTL)
      └─ Updates NgRx store
   ↓
4. Components Load
   └─ All translations available immediately
```

### 2. Language Detection Priority

```typescript
Priority Order:
1. localStorage value (if exists)
   └─ Example: 'fr' saved from previous session

2. Browser language (if no localStorage)
   └─ navigator.language → 'fr-FR' → mapped to 'fr'

3. Default language (fallback)
   └─ 'en' if nothing else matches
```

### 3. Language Switching Flow

```
User clicks language selector
   ↓
LanguageSwitcherComponent.switchLanguage('ar')
   ↓
LanguageService.setLanguage('ar')
   ├─ Validates language code
   ├─ Loads ar.json translations
   ├─ Saves to localStorage
   ├─ Applies RTL direction
   └─ Dispatches setLanguage action to NgRx
   ↓
All subscribed components update automatically
   └─ Translate pipe re-evaluates
   └─ UI re-renders in Arabic
```

## Adding a New Language

### Step 1: Create Translation File

Create a new JSON file in `src/assets/i18n/`:

```bash
# Example: Adding Spanish
touch src/assets/i18n/es.json
```

```json
{
  "common": {
    "welcome": "Bienvenido",
    "logout": "Cerrar sesión",
    "settings": "Configuración"
  },
  "home": {
    "title": "Página de inicio",
    "description": "Bienvenido a nuestra aplicación"
  },
  "errors": {
    "required": "Este campo es obligatorio",
    "invalid_email": "Correo electrónico no válido"
  }
}
```

### Step 2: Update Language Configuration

Edit `src/app/core/i18n/language.config.ts`:

```typescript
export const SUPPORTED_LANGUAGES: LanguageOption[] = [
  { code: "en", label: "English", direction: "ltr", flag: "🇬🇧" },
  { code: "fr", label: "Français", direction: "ltr", flag: "🇫🇷" },
  { code: "ar", label: "العربية", direction: "rtl", flag: "🇹🇳" },
  { code: "es", label: "Español", direction: "ltr", flag: "🇪🇸" }, // ← Add this
];
```

### Step 3: Test the New Language

```bash
# 1. Start the app
ng serve

# 2. Open browser console
localStorage.setItem('app_language', 'es');

# 3. Reload page
# App should load in Spanish
```

### Step 4: Update Browser Language Mapping (Optional)

If you want to auto-detect this language:

```typescript
// language.config.ts - mapBrowserLanguage function
// Already handles this automatically!
// 'es-ES' → 'es'
// 'es-MX' → 'es'
```

## Using Translations

### 1. In Templates (Translate Pipe)

```html
<!-- Simple translation -->
<h1>{{ 'common.welcome' | translate }}</h1>

<!-- With parameters -->
<p>{{ 'greeting.message' | translate: {name: userName} }}</p>

<!-- With default value -->
<span>{{ 'optional.key' | translate | default: 'Fallback text' }}</span>

<!-- In attributes -->
<input [placeholder]="'form.email_placeholder' | translate" [attr.aria-label]="'form.email_label' | translate" />

<!-- In property bindings -->
<button [title]="'common.save' | translate">{{ 'common.save' | translate }}</button>
```

**Translation file example:**

```json
{
  "greeting": {
    "message": "Hello, {{name}}!"
  },
  "form": {
    "email_placeholder": "Enter your email",
    "email_label": "Email address"
  }
}
```

### 2. In TypeScript (TranslateService)

```typescript
import { Component, inject } from "@angular/core";
import { TranslateService } from "@ngx-translate/core";

@Component({
  selector: "app-example",
  template: `<p>{{ translatedText }}</p>`,
})
export class ExampleComponent {
  private translate = inject(TranslateService);
  translatedText = "";

  ngOnInit() {
    // Instant translation (synchronous)
    this.translatedText = this.translate.instant("common.welcome");

    // Async translation (returns Observable)
    this.translate.get("common.welcome").subscribe((text) => {
      console.log(text); // "Welcome"
    });

    // With parameters
    this.translate.get("greeting.message", { name: "John" }).subscribe((text) => {
      console.log(text); // "Hello, John!"
    });

    // Multiple keys at once
    this.translate.get(["common.save", "common.cancel"]).subscribe((texts) => {
      console.log(texts.save); // "Save"
      console.log(texts.cancel); // "Cancel"
    });

    // Listen to language changes
    this.translate.onLangChange.subscribe((event) => {
      console.log("Language changed to:", event.lang);
    });
  }
}
```

### 3. In Validators (Reactive Forms)

```typescript
import { Component, inject } from "@angular/core";
import { FormBuilder, Validators } from "@angular/forms";
import { TranslateService } from "@ngx-translate/core";

@Component({
  selector: "app-form",
  template: `
    <form [formGroup]="form">
      <input formControlName="email" />
      @if (form.get('email')?.hasError('required')) {
      <span class="error">{{ getErrorMessage("required") }}</span>
      } @if (form.get('email')?.hasError('email')) {
      <span class="error">{{ getErrorMessage("invalid_email") }}</span>
      }
    </form>
  `,
})
export class FormComponent {
  private fb = inject(FormBuilder);
  private translate = inject(TranslateService);

  form = this.fb.group({
    email: ["", [Validators.required, Validators.email]],
  });

  getErrorMessage(errorKey: string): string {
    return this.translate.instant(`errors.${errorKey}`);
  }
}
```

### 4. In Route Guards

```typescript
import { inject } from "@angular/core";
import { Router } from "@angular/router";
import { TranslateService } from "@ngx-translate/core";

export const authGuard = () => {
  const router = inject(Router);
  const translate = inject(TranslateService);
  const isAuthenticated = false; // Your auth logic

  if (!isAuthenticated) {
    const message = translate.instant("auth.not_authenticated");
    alert(message);
    return router.createUrlTree(["/login"]);
  }

  return true;
};
```

### 5. In Services

```typescript
import { Injectable, inject } from "@angular/core";
import { TranslateService } from "@ngx-translate/core";
import { HttpClient } from "@angular/common/http";
import { map } from "rxjs/operators";

@Injectable({ providedIn: "root" })
export class NotificationService {
  private translate = inject(TranslateService);
  private http = inject(HttpClient);

  showSuccessMessage(key: string) {
    const message = this.translate.instant(`notifications.${key}`);
    // Show toast/snackbar with translated message
    console.log(message);
  }

  getLocalizedData() {
    return this.http.get<any[]>("/api/data").pipe(
      map((items) =>
        items.map((item) => ({
          ...item,
          // Translate server data
          displayName: this.translate.instant(`items.${item.type}`),
        }))
      )
    );
  }
}
```

## API Integration

### Automatic Language Headers

Every HTTP request automatically includes the current language:

```typescript
// You make a request
this.http.get('/api/products').subscribe(data => {
  console.log(data);
});

// Interceptor automatically adds header
GET /api/products
Headers: {
  Accept-Language: fr
}
```

### Manual Language Header Override

```typescript
// Override for specific request
this.http
  .get("/api/products", {
    headers: { "Accept-Language": "en" },
  })
  .subscribe((data) => {
    // This request uses English regardless of current language
  });
```

### Backend Integration Example

```typescript
// Node.js/Express backend
app.get("/api/products", (req, res) => {
  const lang = req.headers["accept-language"] || "en";

  // Return localized data based on language
  const products = getProducts(lang);
  res.json(products);
});
```

## Troubleshooting

### Problem: Translation key not found

**Symptoms:**

```html
<!-- Displays: "home.title" instead of "Welcome" -->
<h1>{{ 'home.title' | translate }}</h1>
```

**Solutions:**

1. Check if key exists in JSON file:

```bash
# Search for key in translation files
grep -r "home.title" src/assets/i18n/
```

2. Verify JSON syntax:

```bash
# Check if JSON is valid
node -e "console.log(JSON.parse(require('fs').readFileSync('src/assets/i18n/en.json')))"
```

3. Check console for loading errors:

```
Look for: [TranslateLoader] en.json failed ❌
```

### Problem: Language doesn't persist after reload

**Check localStorage:**

```javascript
// Browser console
localStorage.getItem("app_language");
// Should return: 'en', 'fr', or 'ar'
```

**Verify initialization:**

```typescript
// Look for this in console logs
✅ Language initialization complete!
💾 Saved to localStorage: fr
```

### Problem: Flash of English on page load

**Solution:** Add loading screen (see [FOUC Solutions](#fouc-solutions))

```css
/* Hide app until translations load */
body:not(.translations-ready) app-root {
  opacity: 0;
}
```

### Problem: RTL not working for Arabic

**Check:**

1. Verify direction is set in config:

```typescript
{ code: 'ar', label: 'العربية', direction: 'rtl', flag: '🇹🇳' }
```

2. Check if CSS is applied:

```javascript
// Browser console
document.documentElement.dir; // Should be 'rtl'
document.body.classList.contains("rtl"); // Should be true
```

3. Add RTL-specific styles:

```scss
// styles.scss
body.rtl {
  direction: rtl;
  text-align: right;

  .flex-container {
    flex-direction: row-reverse;
  }
}
```

### Problem: Translations not loading in production

**Check build output:**

```bash
# Verify translation files are copied
ls dist/browser/assets/i18n/
# Should show: en.json, fr.json, ar.json
```

**Update angular.json:**

```json
{
  "projects": {
    "your-app": {
      "architect": {
        "build": {
          "options": {
            "assets": [
              "src/favicon.ico",
              "src/assets",
              {
                "glob": "**/*.json",
                "input": "src/assets/i18n",
                "output": "/assets/i18n"
              }
            ]
          }
        }
      }
    }
  }
}
```

## Best Practices

### 1. Translation Key Naming

```typescript
// ✅ GOOD - Clear hierarchy
{
  "auth": {
    "login": {
      "title": "Sign In",
      "submit": "Log In",
      "forgot_password": "Forgot Password?"
    }
  }
}

// ❌ BAD - Flat structure
{
  "auth_login_title": "Sign In",
  "auth_login_submit": "Log In"
}
```

### 2. Parameterization

```json
// ✅ GOOD - Flexible
{
  "welcome": "Welcome, {{name}}!",
  "items_count": "You have {{count}} items"
}

// ❌ BAD - Hardcoded
{
  "welcome_john": "Welcome, John!",
  "one_item": "You have 1 item",
  "two_items": "You have 2 items"
}
```

### 3. Pluralization

```typescript
// Use ngx-translate's plural support
{
  "items": {
    "zero": "No items",
    "one": "One item",
    "other": "{{count}} items"
  }
}

// In template
{{ 'items' | translate: {count: itemCount} }}
```

### 4. Avoid String Concatenation

```typescript
// ❌ BAD
const message = this.translate.instant("hello") + " " + userName;

// ✅ GOOD
const message = this.translate.instant("greeting", { name: userName });
// Translation: "greeting": "Hello {{name}}"
```

### 5. Lazy Load Translations

```typescript
// For large apps, split translations by feature
{
  "common": {},        // Loaded initially
  "admin": {},         // Loaded when accessing admin
  "reports": {}        // Loaded on demand
}

// Load on demand
this.translate.setTranslation('admin', adminTranslations, true);
```

### 6. Keep Translations in Sync

```bash
# Use a tool to validate all languages have same keys
npm install -g i18n-sync

# Check for missing keys
i18n-sync --check src/assets/i18n/
```

## Advanced Features

### 1. Language-Specific Date/Number Formatting

```typescript
import { formatDate, formatNumber } from "@angular/common";

@Component({
  selector: "app-example",
  template: `
    <p>{{ formattedDate }}</p>
    <p>{{ formattedNumber }}</p>
  `,
})
export class ExampleComponent {
  private translate = inject(TranslateService);

  formattedDate = formatDate(new Date(), "fullDate", this.translate.currentLang);

  formattedNumber = formatNumber(1234.56, this.translate.currentLang, "1.2-2");
}
```

### 2. Dynamic Translation Loading

```typescript
// Load translations on demand (e.g., for dialects)
async loadTunisianArabic() {
  const translations = await import('./assets/i18n/aeb-TN.json');
  this.translate.setTranslation('aeb-TN', translations, true);
  this.languageService.setLanguage('aeb-TN');
}
```

### 3. Translation Missing Handler

```typescript
// app.config.ts
import { MissingTranslationHandler, MissingTranslationHandlerParams } from "@ngx-translate/core";

export class CustomMissingTranslationHandler implements MissingTranslationHandler {
  handle(params: MissingTranslationHandlerParams) {
    console.warn(`Missing translation for key: ${params.key}`);
    return `[${params.key}]`; // Show key in brackets
  }
}

// Add to providers
provideTranslateService({
  missingTranslationHandler: {
    provide: MissingTranslationHandler,
    useClass: CustomMissingTranslationHandler,
  },
});
```

### 4. SEO with Language Meta Tags

```typescript
import { Meta } from "@angular/platform-browser";

@Component({
  selector: "app-root",
})
export class AppComponent {
  private meta = inject(Meta);
  private translate = inject(TranslateService);

  ngOnInit() {
    this.translate.onLangChange.subscribe((event) => {
      this.meta.updateTag({
        name: "description",
        content: this.translate.instant("meta.description"),
      });

      this.meta.updateTag({
        property: "og:locale",
        content: event.lang,
      });
    });
  }
}
```

### 5. Testing Translations

```typescript
// Component test with translations
import { TranslateModule } from "@ngx-translate/core";

describe("MyComponent", () => {
  beforeEach(async () => {
    await TestBed.configureTestingModule({

    expect(fixture.nativeElement.textContent).toContain("Hello World");
  });
});
```

## Performance Optimization

### 1. Translation File Size

```bash
# Keep translation files small
# ✅ GOOD: < 50KB per file
# ⚠️ WARNING: 50-200KB (consider splitting)
# ❌ BAD: > 200KB (definitely split)

# Check file sizes
du -h src/assets/i18n/*
```

### 2. Preload Critical Languages

```typescript
// In APP_INITIALIZER, preload commonly used languages
async preloadLanguages() {
  const promises = ['en', 'fr'].map(lang =>
    firstValueFrom(this.translate.getTranslation(lang))
  );
  await Promise.all(promises);
}
```

### 3. Use ChangeDetection.OnPush

```typescript
// Reduce unnecessary checks
@Component({
  selector: "app-example",
  changeDetection: ChangeDetectionStrategy.OnPush,
  template: `{{ "key" | translate }}`,
})
export class ExampleComponent {}
```

### From Old System to This System

If migrating from a different i18n solution:

2. **Match key structure** to new format
3. **Update components** to use translate pipe
4. **Test thoroughly** with each language
